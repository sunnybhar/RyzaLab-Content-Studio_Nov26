# Agent Rules — stored only

Open Manage → Agent Rules. Select the social channel and upload separate Instructions and Context files. Original DOCX/PDF/TXT/Markdown files are preserved for download; replace/remove controls are available. The user's personal example DOCX was used to understand the headings and was not installed as RyzaLab rules.

Inside the page, RyzaLab tone and original content voice holds multiple labelled article, post and newsletter examples. Choose Copy and paste text or Upload a file, enter a title/category, choose whether it is brand-wide or specific to the selected channel, then Save original content example. Brand-wide examples appear for all channels. Read pasted originals or download the original files to inspect them.

Nothing in this section is parsed, executed, added to active workflow references or sent to existing idea/research/writing agents. There is no connection/activation button. These materials are for a later explicitly authorized integration.

Limits: 256 KB per file, 60,000 characters per pasted example, 100 voice examples within workspace storage limits. Workflow-edit channel permissions control access. Duplicate request keys and stale slot replacements do not silently overwrite other people's changes. Uploading/storing examples creates no AI jobs and requires no model budget.
