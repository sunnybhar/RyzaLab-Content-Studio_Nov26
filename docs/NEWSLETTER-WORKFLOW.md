# Newsletter and article writing in v0.3.16

1. Open AI & budgets → Bounded research and writing. Existing users should run Check model and enable bounded workflow once to qualify the larger writing output limit. This is a capability/setup check, not a paid generation. New writing qualification allows 4,096 output tokens; ideas/review remain 2,048. The conservative maximum is 18 cents per writing request at the supplied prices. Existing founder monthly, request and package limits still apply. Active/uncertain jobs must be resolved before changing setup; no automatic paid retry occurs.
2. In Agent Rules select Newsletter, upload a Hub package, preview/edit the Instructions and context and save. Alternatively upload individual files and voice examples. Users own this step; attached chat files are not installed by the assistant.
3. Generate/select a Newsletter idea and open its draft, or select an article/newsletter format in Create. Writing shows queued, waiting-for-confirmation, running and attention states with elapsed time. The status button refreshes the same request and does not enqueue another one. Completed or recoverable unfinished text appears in the writing box.
4. Newsletter/article instructions request 1,200–1,600 words with background, evidence/data where supported, reasoning, practical implications, limitations, conclusion and readable source citations. LinkedIn social posts remain concise (180–250 words by default); their provenance stays separate from the post body. AI newsletters below 1,200 words or without sources retain confirmation blockers until edited. No statistics or sources should be invented just to fill the length.
5. The model returns a relevant image brief, not image pixels. In Write → Newsletter image and exports, upload an appropriate image or use an accessible image URL. The chosen image is previewed and saved with the draft; existing image integrations remain separately qualified. There is no implicit paid image generation.
6. Export newsletter PDF or Export newsletter DOCX includes the current text, readable Sources section and attached hero image. The PDF paginates automatically and DOCX uses normal Word pagination. A substantive 1,200–1,600-word newsletter is normally at least 2–3 pages; exact page count depends on headings, image proportions and layout. Editing a draft shorter does not add meaningless blank pages to its export. Exporting does not approve or publish content.

Local tests cover package editing, skill guidance, source preservation, image embedding, multi-page PDFs and writing status. Hosted provider execution and actual live generation costs remain unverified; no paid live calls were made during this build.
