# RyzaLab Studio 0.3.0

This release implements the approved solo-founder workflow: compact Ideas and reviews, linked drafts with guarded automatic first writing, two human review decisions with truthful textual-review reports, exact approved-package calendar planning/preview, simpler channel navigation, provider account-model discovery, safe connection editing, and a versioned qualified-price registry.

Existing workspaces retain their current review policy until a founder explicitly adopts the new process. The initial suggested caps are $0.50/package and $5/month; publication remains manual. No migration, live provider test, existing budget change or automatic founder claim is part of deploying this release.

For an administrator-only workspace, the deployment owner must configure server-only STUDIO_FOUNDER_EMAIL to the intended verified administrator sign-in email before that person can explicitly claim the first founder role in AI & budgets. Existing founders retain control of later founder membership changes. See FOUNDER-SETUP.md. Configure/validate writing and review bindings plus qualified prices before expecting AI work. Media integrations and social metrics retain their previously deferred qualification status.

Release evidence:170 automated checks, optimized build, full browser walkthrough, isolated founder/settings, pricing/connection, first-writing and review-to-calendar fixtures, plus real local PostgreSQL composed-CAS regression. No evidence asserts live credentials or paid provider acceptance. Training refreshed to14 modules/172manualQA cases/62backlog items; manual cases remain Not run. Current live acceptance and deployment confirmation must be recorded separately.
