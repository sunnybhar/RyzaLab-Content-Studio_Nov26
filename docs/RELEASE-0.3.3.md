# 0.3.3 — Create composer, saved writing recovery and newsletter sources

Create now keeps writing controls inside Write, with optional instructions and technical results collapsed. Completed first writing fills an unchanged empty editor; unanswered factual questions are retained as explicit confirmation markers in publication notes and block copy approval. Existing human copy is protected by revision and exact-context checks. A saved alternative can be opened for editing explicitly; previous copy remains in history and AI provenance is retained.

Saved completed writing responses with bounded flat metadata objects are normalized to readable publication notes. Prepare saved draft — no AI call reparses an eligible stored response without contacting a provider, changing its cost reservation or replacing the draft. Open suggested text in editor then loads it for editing; this is not factual approval. Raw responses and every question/source remain retained.

Preview post opens a read-only approximate feed popup using current editor text, including unsaved edits, attached image, carousel and source video/audio scenes. Publication notes and raw JSON are excluded from post text. Native dialog supports Escape and focus return. This is not an exact platform rendering or an external publishing action.

Slides and video/audio have contextual assistance entry points. Image/audio/video providers still require qualification and configuration; this release does not enable them or web search. Carousel copy uses the configured writing connection and the selected carousel format.

Create newsletter from this is available on LinkedIn/Reddit drafts; ideas have Create newsletter from this idea. The action creates/reopens a manual Newsletter draft with a source snapshot and revision, preserving the source and starting no AI work. Write with AI uses the Newsletter writing setup and includes that source. Source read access is checked again at generation and dispatch. Repeated use of the same source revision reopens the linked draft.
