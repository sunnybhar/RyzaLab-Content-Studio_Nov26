# v0.3.37 — research first: reusable sources for ideas and writing

This is the shortened IB-15 increment requested to unblock source-backed work. It does not ship the full claim ledger or data-analysis interface. Other backlog areas remain paused.

- Bounded discovery now pursues specialist sources, original documentation/studies, contrary evidence and wider reporting. Focused/deep/extended profiles use two/four/six public questions. Search queries use the explicit public topic and public Source Preferences; private writing/research files never enter public search queries.
- Accessible article passages and searchable public PDFs are read with existing HTTPS/DNS/redirect/private-network guards. PDF text retains page labels, with a 512 KB, 20-page and 16,000-character extraction bound; no OCR, video watching or verified table reconstruction is claimed. Inaccessible sources remain labelled excerpts or explicit gaps. Exact repeated passages are removed; different domains do not prove independent origins.
- Saved research records include the investigation plan and observed reading/excerpt coverage. Source and time bounds can yield useful partial coverage, not a promised source quota.
- Automatic idea research is committed separately before idea enqueue. If later generation fails, research remains available; retries with the same operation reuse its saved evidence rather than repeating discovery.
- Ideas offers **Use saved research or add source links**. Select completed permitted research and generate ideas without another public search. Selected evidence is also retained for manually saved ideas and carried into writing through the existing immutable research snapshots.

How to use:
1. Ideas → Generate with agent or Add manually → **Use saved research or add source links**.
2. Select saved evidence, or expand **Find public references**, enter a public question and optional article/PDF URLs, then choose **Find references**.
3. Tick **Use this evidence in idea generation**, then generate/develop the idea. With no selected evidence, the normal automatic-research path remains available.
4. Choose **Use idea and open writing**. Its research is carried into the draft. In an existing draft, use **Web research** to retrieve/select evidence, then explicitly write/revise with AI.

No new research API key or paid analysis stage is required by this increment. Paid Ideas/Writing still need a validated connection, qualified rates and current allowance. Prior uncertain paid outcomes retain their reservations; deployment does not manufacture their resolution or bypass limits. No evidence result means no source-backed generation is started.

Validation: focused query/PDF/provenance/recovery tests and a browser flow from saved source → generated ideas → source-backed writing. Final regression/build/smoke recorded in WORK-IN-PROGRESS.md. These use local provider fixtures; live current-source quality and configured provider/worker acceptance remain unverified. Full dossier/claim ledger/reproducible data-analysis code is retained separately as WIP, not released.
