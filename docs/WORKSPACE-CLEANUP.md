# v0.3.25 review guide

Active channels: LinkedIn, Instagram, YouTube, Reddit and Newsletter. Notes/Notebook, Hub, TikTok and Facebook are removed from visible channel lists, records and selectors across workspace sections. New live requests from stale tabs are rejected, automatic preparation skips retired channels, and retired queued work cannot dispatch. Historical records and billed/uncertain amounts are not deleted. Budget totals still include the entire ledger.

The header reads **RyzaLab Content Studio**. Command Center, Production Board, What's new, Appearance and Manual publishing are below Manage in the sidebar (scroll the sidebar if needed). Notifications and profile stay in the header.

Ideas request history shows a durable IDEA request number, requested date/time and original topic/brief. Generated idea cards show their generated date and originating request/topic when recorded. Older requests without an original topic are labelled honestly. Raw provider JSON is removed from normal Ideas; diagnostic provider results remain in AI & budgets.

Open **Ideas → Compare 4 Ideas layouts**, or **/ideas-layouts**. Four interactive sample-data previews are available: 1. Group by request (recommended), 2. Compact table, 3. Inbox and detail, 4. Idea board. They make no AI calls and do not modify real ideas. The final full Ideas layout awaits the user's choice; metadata/navigation changes are already implemented.

The editor's old right-side support panels now sit under collapsed **More options**. They retain assignment, backup/source exports and image tools. Normal PDF/DOCX newsletter export remains immediately below the writing box.

## Agent Rules verification
Canonical LinkedIn-post and Newsletter generation tests hydrate and enqueue matching Instructions (including appended skill guidance), Context/knowledge and shared voice. They verify those markers in the actual saved compiled model system, exclusion of the other channel's files, distinct channel-length contracts, and unchanged request context after later uploads. The provider adapter sends that frozen system. No production credentials or paid calls were used; inclusion tests do not prove stylistic compliance in every output.

**Agent Rules used for this writing request** beneath the content box lists the rule files and voice examples selected in the compiled context. Older jobs without exact compiled context are labelled as snapshot-only. Long context may use selected excerpts. Files uploaded after a request do not retroactively change it; a new request uses the updated saved files.

Validation: 265 domain tests; final focused Agent Rules/channel tests; production build/typecheck; full browser workflow; focused navigation/metadata/preview/mobile browser. Hosted deployment and live provider behavior remain unverified until checked in the app.
