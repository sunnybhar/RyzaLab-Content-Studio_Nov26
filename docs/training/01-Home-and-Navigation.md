# RyzaLab Training — Home and Navigation

Version: 2026-10-30 | Audience: All users

## Objective
Find work quickly using the dashboard, channel filter, layouts and sidebar.

## Before you start
Have access to preview or a live workspace.

## Availability
Available in preview. Live operation requires the configured /studio workspace. Release 0.3.2: the two-decision flow requires explicit founder adoption; any legacy stage instructions below apply only before adoption. No paid provider or live-account acceptance is implied by these documents.

## Step-by-step workflow
1. Open Home. Read the current mode before entering important work.
2. Choose Command Center or Production Board in the top bar. Command Center shows channel tiles, totals and upcoming work; Production Board groups the same content by progress.
3. Choose All channels or a channel to narrow the visible records. Changing layout does not create copies of your content.
4. Use the sidebar icons to open Ideas, Calendar, Create, Reviews, Library, Analytics, Workflow settings, People & access, AI & budgets and Notifications.
5. Use Collapse sidebar / Expand sidebar to change its width. Use Unpin sidebar for an on-demand drawer; Open menu opens it. Pin sidebar makes it persistent on desktop.
6. On mobile, Open menu reveals navigation. Close it with the close control or Escape. The drawer should not remain over the selected page.
7. Open Appearance to choose display settings, then Open selected layout to return Home.

## Expected result
The selected layout and navigation preferences survive a refresh for the same account on that device.

## Practice exercise
Switch to Production Board, refresh, switch back, collapse the sidebar, unpin it and reopen it.

## Common problems and boundaries
If records seem missing, check the channel filter and search. Browser preferences are local and are not account settings synchronized across devices.
