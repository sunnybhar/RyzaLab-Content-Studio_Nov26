# RyzaLab Training — Create — Writing, Slides and Scenes

Version: 2026-10-28 | Audience: Creator or editor assigned to the item; founder/admin as permitted

## Objective
Create and maintain the written draft and selected media as separate dependencies.

## Before you start
Start from an approved idea or Create content. Know your intended channel and format.

## Availability
Available in preview. Live operation requires the configured /studio workspace.

## Step-by-step workflow
1. Open Create and click a content title, or Create content and enter its working title, channel, format and optional publication account.
2. Edit Content text, title and metadata. Replace placeholders with verified facts; do not invent personal experience or unsupported promises.
3. Save draft before switching work. Concurrent edits can be rejected rather than silently overwriting another editor; reload and compare versions.
4. For carousels, use the slide editor for copy and layout. Add text/shape layers, drag or nudge with arrow keys, edit size/color/opacity, reorder, duplicate or remove; save the draft. Layers appear above base copy and their wording is included in factual checks even when transparent. For video, use scenes, scripts, narration, captions and aspect ratio controls. Script-only scenes are not finished rendered video.
5. Use available generation controls only with a live qualified provider; preview must not be treated as genuine model output. Review every generated result.
6. Use DOCX import/export as needed. A linked Google Doc requires live OAuth configuration; preview fetching intentionally reports unavailable. Optional automatic mode requires founder authority and an initial manual fetch. Conflicts and approved versions hold incoming text for comparison/manual import; displaced branches stay in history.
7. Use editable source export to retain supported slide/scene data. PNG/PDF are flattened exports; they are not a full design-editor source format.
8. Complete the visible stage checks and Submit for review. Do not claim Independent review was an agent review unless a real review result supports it.
9. When changing approved text, keep the old approval snapshot. Recheck affected stages; unchanged media need not be generated again.

## Expected result
The draft saves with a new revision; text edits preserve unchanged visual review while affected factual/release checks reopen.

## Practice exercise
Create a text post, save it, export DOCX, change one paragraph and save again. Verify the previous version remains in history.

## Common problems and boundaries
Cannot approve video: complete scene media, not just scripts. Cannot save: check stale revision errors and required fields. Uploaded media must be retained Studio assets for live package approval.
