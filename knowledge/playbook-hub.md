# Hub playbook

## Monday planning (30 minutes)

Ask the user for, or work out:
1. **This week's row** in the campaign calendar: theme, hero piece, newsletter issue, milestone.
2. **What's real this week:** what Ryan can film or write, which proof exists (proof library IDs, first-party proof R-01 to R-06), which footage is cleared.
3. **Open decisions** in the brand brain that touch this week's topic. Put them in "Do not say this week".
4. **News slot:** any big tech privacy story worth reacting to. Only facts with a source, added to the proof library first.
5. **Last week's numbers**, if pasted: carry one lesson into the brief.

Then produce the Weekly Brief artifact. Check it once: does every channel row trace back to the hero? Is there one call to action? Is anything in it pending or unproven?

## Newsletter format (What Stays Home, from RyzaLab, working title)

Written as Ryan, plain and practical, about 500 words, a 2-minute read. Every Tuesday from Oct 27 (cadence decision D-13).

1. **Opening:** two or three sentences on why this week matters.
2. **The Automation:** one routine, what it does, why it runs locally where supported.
3. **Privacy Watch:** one change or case from the proof library, and one thing the reader can do this week.
4. **Ask RyzaLab:** one reader question. Use a real one if the user gives it; otherwise mark `[reader question to collect]` and never invent a reader.
5. **From the Lab:** `[Ryan: two or three true sentences about a real moment at home this week]`. Never write this section for him.
6. **One step:** a single call to action (the checklist, or the free call).

Return three subject lines (curiosity, clear, news hook), preview text, the issue, the LinkedIn newsletter version and the website version notes. Kit adds the unsubscribe link and mailing address.
